# tindahan-app
An offline Android inventory app for a sari-sari store.

Stack: Kotlin, XML + ViewBinding, Room (SQLite), simple MVVM/Repository. No network, no backend.
See CLAUDE.md, ARCHITECTURE.md, DATA_RULES.md, DEBUGGING.md.

## Roadmap
- Stage 1: data layer + core (done)
- Stage 2: inventory screen: list, search, add/edit/delete dialog (done)
- Stage 3: price calculator: pick product, quantity, running total, cash/change (done)
- Stage 4: dashboard + polish (done)
